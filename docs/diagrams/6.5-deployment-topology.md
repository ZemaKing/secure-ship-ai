# 6.5 Deployment / local dev topology

> Regenerated against the actual `docker-compose.yml` (Week 5). Corrected from the `REQUIREMENTS.md` Mac-oriented starting reference: this build runs on Windows (Docker Desktop, WSL2 backend) — `host.docker.internal:11434` resolves identically, so the topology itself doesn't change, only the host label and the "full Metal acceleration" framing (this machine has no dedicated GPU either way, so Ollama is CPU-only whether host-native or containerized — that's *why* containerizing it was a low-risk Week 5 stretch goal here rather than the genuine performance trade-off the Mac doc describes). Frontend serves on **`:5173`** (Vite dev server), not `:3000`. Twilio was never built — it stayed a documented "optional stretch" that was never picked up; shown here only as explicitly not implemented, not as a live integration point.

Twilio (real SMS) was never built anywhere in this repo; the mock-SMS path (`tools/send_verification_code.py`, console `print()` only) is the only implementation that exists, and is not shown in this diagram as a live external dependency.
